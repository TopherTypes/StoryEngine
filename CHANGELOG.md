## Notes

### v0.1.0 (MVP) Success Criteria

**Story Authoring Tool**
- ✓ Create complete 50-150 artefact stories
- ✓ Support mixed timed and gated progression
- ✓ Preview and debug without code edits
- ✓ Export story data consumable by Player

**Player App**
- ✓ Display convincing faux desktop
- ✓ Unlock content on time/gate conditions
- ✓ Persist progress across sessions
- ✓ Support password-locked content
- ✓ Trigger custom endings

### v1.0+ (Future Enhancements)

- Story import/export with bundles
- Multiple desktop themes
- Advanced preview features (jump timeline, force-unlock, inspect state)
- Cloud save sync
- Creator story library/publishing
- Additional file types (PDF, spreadsheet)
- Search and filtering
- Notification/reminder systems
- Branching narrative support
- Collaboration features
