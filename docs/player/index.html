Story Player

Welcome to the StoryEngine Story Player. This is where you load and experience ARG stories in an immersive desktop environment.

How to Play

  1. Load a story from a JSON file or enter a story URL
  2. Log in through the story's custom login screen
  3. Explore the simulated desktop environment
  4. Discover emails, messages, documents, images, and audio
  5. Unlock content through discovery and time progression
  6. Reach the story's ending and uncover its secrets

Features (Coming Soon)

  • 🎮 Immersive desktop environment with multiple app windows
  • 📧 Email, IM, Calendar, File Explorer, Document Viewer, and more
  • 🔓 Progressive unlocking based on time and interactions
  • 🔐 Password-protected content
  • 💾 Automatic session persistence across browser sessions
